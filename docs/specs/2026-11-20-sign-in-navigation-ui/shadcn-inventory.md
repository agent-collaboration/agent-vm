## Inventory

`UI/<name>.tsx` means `packages/tool-access-ui/src/components/ui/<name>.tsx` at the pinned tree, with the shared exports described above. `Add` gives the registry item to install in the shared Base Mira UI package. `Copy` means the cited Better Auth UI Base UI example and its local dependencies. **Stock** is one registry component family or a whole upstream view reused in its shipped form. **Composition** uses actual primitives in a documented layout or usage pattern. **Snowflake** flags a hand-styled element described in the mockup notes or present in the proposed local reuse. The tables give the proposed component for each visual role, including states the commission names without a separate image.

The [Button link docs][button-link] document link styling, but that example cannot establish a stock fixed bar.
