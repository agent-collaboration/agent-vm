F2 · Hegel on critical systems: Verification Design

Each target counts only if a deliberately wrong build, in a scratch copy, makes its named property fail with a shrunk case, and the restored build passes again.

TargetWrong build that must fail
P1verify ignores digest order, or skips the expiry check

P3the path check normalizes after matching (so a/../../x passes)
P4normalization drops the kind check
P5uses the granted scopes without intersecting with the ceiling
P6the compiler iterates an unordered map, so the digest isn't deterministic; or it unions the authored grant with a default
P7pattern redaction misses JSON-escaped secrets
P8pagination off-by-one at the page boundary
P9host comparison case-insensitive on a configured exact host, or one that ignores the port
M1use doesn't mark the token consumed

M3transitionIsAllowed permits activate from a terminal state

Each red is recorded with the property name, the shrunk values or steps, and the seed, then restored green. Unit and integration rows run locally and in CI; M4 runs on Sunclaw (host lane) and in CI.
