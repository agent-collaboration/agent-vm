F2 · Hegel on critical systems: Specification

What must be true, per target. Every target and anchor comes from the source collection in tmp/2026-11-17-f2-research/report.md (public Switchboard b03d35ff). The ranking is mine. Each target's property is judged against an independent oracle: a small model, a round trip, or a stated rule. The product's own code is never the oracle.

Pure decisions (unit lane)

IdTarget (package · function)Property that MUST hold for every generated input
P1tool-engine · sign/verifyAudienceScopedApprovalToken, receiptMatchesRound trip: a token signed for (audience, ordered digests, time window) verifies only for exactly those values. Changing any field, the order, the audience or the key, or moving past expiry, is refused.
P2tool-access · resolvePortalAccessPolicy, mcpPortalCallPolicyDecision, createAccessAssessorDeny by default: a tool not reachable through any granted selector is denied. Monotonic: adding a grant never removes an allow, and removing a grant never adds one. The decision is the same for the same inputs.
P3tool-access · evaluateCliAllowanceInvocation, classifyCliPathContributionGenerated argv is allowed only when an allowance matches it by its stated rule. A path argument that escapes its allowed root (.., absolute, encoded, Unicode lookalikes) is never allowed.
P4oauth-broker-contracts · normalizeGogFileArgument, createGogOperationResolverA normalized file argument never resolves outside its permitted kind and root; operation classification gives the same answer before and after normalization.
P5oauth-broker · evaluateGoogleOperationGrant, compileGooglePermissionSelectionModel oracle: an operation is allowed only when its required scopes are within (granted ∩ ceiling). Compiled selections never exceed the ceiling.
P6config-contracts · toolPortalConfigSchema, compileCommandSet, compileOAuthPolicyCompiling is deterministic (same input, same output and digest). Compiled grants never exceed what the config authored. Invalid configs are refused with a schema error, never a crash.
P7tool-engine · exact and pattern redactionFor any secret embedded anywhere in any value (prefix, suffix, JSON-escaped, nested), the redacted output never contains the secret.
P8tool-engine · encode/decodeToolRef, paginateMcpTools; tool-engine and tool-access canonical digestsRound trips are exact. Pagination returns every tool exactly once. Canonical digests don't depend on key order, and different values give different digests.
P9tool-host-node · credential parse/authenticate, Host/Origin/request-target checksOnly the exactly configured hosts, origins and credentials pass; generated header variants (case, ports, trailing dots, Unicode, extra slashes) never pass when they don't match.

Stateful flows (integration or host lane, Hegel StateMachine)

IdTargetOperationsInvariants checked every step
M1tool-engine · createInMemoryApprovalTokenUse; tool-host-core · decideApprovalTokenUseissue, use, expire (injected clock), replayA token is used at most once; it's never used after expiry; the byte and count caps are never exceeded
M2oauth-broker · OAuthTransactionStore, continuations, sessionscreate, read, consume, cancel, expireConsume at most once; nothing consumed after cancel or expiry; the capacity bound holds; one browser identity can't consume another's
M3tool-host-node · operation store (transitionIsAllowed, reserve, arm, prove-not-dispatched, activate)each transition in any orderNever dispatched twice; terminal states are final; only allowed transitions commit (checked by compare-and-set)
M4tool-host-core · createWorkspaceAuthority, agent removaladmit, remove, re-add, retireA removed or retired agent is never admitted; removal is idempotent
M5agent-portal-sdk · framed JSON-RPC receive, request, cancel, closegenerated frames, including malformed and oversized onesEach pending ID is settled once; frames beyond the bound are refused; nothing is left after close

Limits: sequential only (Hegel runs one step at a time); local stores and hosts; no real Google or upstream MCP servers.
