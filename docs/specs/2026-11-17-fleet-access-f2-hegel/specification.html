Every target and anchor comes from the source collection in tmp/2026-11-17-f2-research/report.md (public Switchboard b03d35ff). The ranking is mine. Each target's property is judged against an independent oracle: a small model, a round trip, or a stated rule. The product's own code is never the oracle.

Pure decisions (unit lane)

IdTarget (package · function)Property that MUST hold for every generated input
P1tool-engine · sign/verifyAudienceScopedApprovalToken, receiptMatchesRound trip: a token signed for (audience, ordered digests, time window) verifies only for exactly those values. Changing any field, the order, the audience or the key, or moving past expiry, is refused.
P2tool-access · resolvePortalAccessPolicy, mcpPortalCallPolicyDecision, createAccessAssessorJudged against an independent decision table per entry: defaults, override precedence, trusted annotations, explicit denials, and the assessor's other prerequisites. Monotonic only for genuine selector-set extension or removal with every other input fixed. The allow-all and trusted-read-only examples pass; an untrusted annotation and a denied selector fail. The unknown-tool case follows the selected default and call-policy mode.
P3tool-access · evaluateCliAllowanceInvocation, classifyCliPathContributionAbout authored command policy only: command paths, matcher AND/OR rules, deny/ask/baseline precedence, flag values and stdin bounds, judged against an independent table. An ordinary path-looking positional value stays permitted when the authored policy permits it. Filesystem containment isn't tool-access's job, and it stays at P4.
P4oauth-broker-contracts · normalizeGogFileArgument, createGogOperationResolverThe existing relationship from raw argv to normalized metadata holds: file and directory are distinguished, the argv is unchanged, root output directories are allowed and input directories are refused. Metadata is never re-read as argv.
P5oauth-broker · evaluateGoogleOperationGrant, compileGooglePermissionSelectionModel: known operation and family, selected group membership within the ceiling, exact scope equality, and complete local service and effect support. Both admitted and refused outcomes are covered. Expected scopes come from independently checked literal and catalog cases, never from the compiler under test. The existing refusal of gmail-write without helper-read is kept.
P6config-contracts · toolPortalConfigSchema, compileCommandSet, compileOAuthPolicyThree outcomes kept apart: a structural schema failure, a declared semantic compile refusal, and an unexpected failure (never allowed). The same input always gives the same output. Order doesn't matter only for fields whose contract says so. The private compiler is exercised through its owner. Compiled grants never exceed what was authored: for example, for each emitted descriptor d, d.paths equals (authored command paths ∩ the independently known catalog paths for d.operationId). Help and version paths stay in noOAuthPaths, and the multi-command search+send case (oauth-policy-compiler.unit.test.ts:227) passes.
P7tool-engine · exact and pattern redactionSeparate properties for each contract: exact-value redaction, recognized-pattern redaction, credential-key redaction and parsed-value redaction. Generated credentials are non-empty and can't overlap the marker. Ordinary data is preserved. Escaped cases are tested at the serialization layer that owns them; there's no universal secret decoding.
P8tool-engine · encode/decodeToolRef, paginateMcpTools; tool-engine and tool-access canonical digestsEach digest has its accepted domain, canonical equivalences and committed fields, with frozen byte and digest vectors kept, and generated changes to the committed fields must change the digest. Pagination equals the original ordered list when every item fits; an oversized item or invalid cursor is refused. Boundaries are measured in serialized UTF-8 bytes, independently of the product's budget helper.
P9tool-host-node · credential parse/authenticate, Host/Origin/request-target checksHost and Origin canonicalization specified separately, as the code does them, plus the missing-Origin and origin-form request-target behaviour. Bearer tokens match byte for byte. A foreign authority, or a target outside the allowlist, is refused.

M5agent-portal-sdk · framed JSON-RPC receive, request, cancel, closereal frames over a Unix socket: request, abort, late reply, closeAbort releases its pending slot before any late reply; the late cancelled reply is tolerated; the next request succeeds; close rejects outstanding requests and prevents further use. Limits: sequential only (Hegel runs one step at a time); local stores and hosts; no real Google or upstream MCP servers.
