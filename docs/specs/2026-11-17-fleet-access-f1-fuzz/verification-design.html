F1 · Fuzz testing for sign-in: Verification Design

A fuzz test is proof only if it can fail. Every row needs:

  • the clean build to pass;
  • a deliberately wrong build, in a scratch copy, to fail with the named property (an exit code alone doesn't count);
  • the restored build to pass again.
