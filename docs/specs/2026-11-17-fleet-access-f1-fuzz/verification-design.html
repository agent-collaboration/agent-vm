F1 · Fuzz testing for sign-in: Verification Design

A fuzz test is only proof if it can fail. Every row below names a deliberately wrong build that the fuzz test must catch, run in a scratch copy and then restored. A clean fuzz run alone proves nothing.

RowProven byWrong build that must fail itWhere
