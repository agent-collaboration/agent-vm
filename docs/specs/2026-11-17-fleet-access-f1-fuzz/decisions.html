Decision F1-2 · Should Bombadil run in CI?

The Hegel tests join the unit, integration and host suites that CI already runs, so they need no new gate. Bombadil is different: a 5-minute real-Chrome exploration per page per host, from a 0.x experimental tool, with no seed, so one run can find what another misses. Adding it to CI is a new gate, and gate changes are yours.

Decided by you

  • Use Hegel for fuzz testing: “yes i hegel is fuzz testing we hsoudld use it” (17 Nov).
  • UI fuzz testing with Bombadil: “and ui fuzz testing with bombardil if we need it as a later step”, then “did you add diesgns and paln out and execute fuzz testing? for heagel ts and bombardil ts?” (17 Nov).
  • Property-based testing is the norm; proof never changes in a move: AGENTS.md rules 6 and 7, PR #297 (17 Nov).
